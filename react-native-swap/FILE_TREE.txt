    ↓

    ↓
Debounced Function (1s delay)
    ↓
API Call (mock or real)
    ↓
Redux State Update
    ↓
Components Re-render
    ↓
UI Updates (with animation)

ANIMATIONS (4 types):

1. Swap Transition
   - Duration: 300ms
   - Type: translateY
   - Trigger: Swap button press

2. Dollar Pulse
   - Duration: 2s cycle
   - Type: scale (1.0 → 1.1)
   - Repeat: Infinite

3. Button Shake
   - Duration: 400ms
   - Type: translateY (±5px)
   - Trigger: Every 10s

4. Loading Pulse
   - Duration: 1s cycle
   - Type: scale (1.0 → 1.1)
   - Trigger: When fetching rates
